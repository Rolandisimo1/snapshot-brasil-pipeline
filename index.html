Snapshot Brasil

Camera-trap analysis pipeline — teaching modules, data, and code

This site collects the analysis modules for the Snapshot Brasil camera-trap network: a step-by-step workshop pipeline covering data structure, environmental covariates, and species-level modeling, built on a merged dataset spanning three camera-trap networks (Snapshot Brasil, the Atlantic Forest camera-trap compilation, and public Wildlife Insights projects). Every module is available in English and Portuguese, as a rendered report (view in your browser) and as an annotated R script (download and run yourself).

Data structure (deployments, sequences, arrays), species/effort overview, camera trap-type and height, the independence-interval choice, and how a detection history is built.

Snapshot Brasil

Pipeline de análise de armadilhas fotográficas — módulos didáticos, dados e código

Este site reúne os módulos de análise da rede de armadilhas fotográficas Snapshot Brasil: um pipeline de workshop passo a passo cobrindo estrutura de dados, covariáveis ambientais e modelagem em nível de espécie, construído sobre um conjunto de dados combinado que abrange três redes de armadilhas fotográficas (Snapshot Brasil, a compilação de armadilhas da Mata Atlântica, e projetos públicos do Wildlife Insights). Cada módulo está disponível em inglês e português, como um relatório renderizado (visualize no navegador) e como um script R anotado (baixe e execute você mesmo).
